6. Manual crawl run

        
주의: 이 버튼은 실제 크롤링을 실행한다(Celery 큐잉). 흐름은 보통 (1) 탐색(discover) → (2) 수집(collect) 순서다. 탐색은 회사 홈페이지에서 채용/구인 페이지 URL을 찾는 단계이고, 수집은 탐색된 채용 페이지를 읽어 공고 상세를 DB에 upsert하는 단계다.
